## 購買內容與價格

原價 NT$6,660，優惠期間 NT$3,860／單一專案；一次付款，非訂閱。未公告優惠截止日，不使用虛構倒數。購買前顯示本筆訂單金額；訂單成立後不因調價更改已成立金額。

包含逐步圖解教學、選單與互動設計工具、單一 LINE 會員專案開通及 **5 次 AI 建置**。建置使用平台的 OpenAI API，正式 OA 的營運 AI 仍需使用者自行設定自己的 API 與負擔費用。

「1 次建置」定義為成功產生並保存一份新版本網站草稿。處理中暫占 1 次，失敗／中斷不扣；同版本重新讀取不重複扣。改需求後重新產生新草稿會使用另一次。免費保存設計／預覽、讀取既有成果、部署既有草稿不扣 AI 建置次數。人工處理的特殊狀況依紀錄核對，不自動重跑付費 API。用完後另行洽詢加購並確認金額，不自動續扣；尚未提供線上額度加購。

付款開通不等於已部署或已通過驗收。使用者須完成自己 LINE、GitHub、Supabase 的註冊與授權。GitHub 網站現階段以專用新專案的靜態網站部署為主，既有網站或 Webhook 衝突可能需先協助處理；非所有任意功能都能自動建置。

不包含：LINE OA 訊息費、GitHub／Supabase 付費方案、正式營運 AI 費用、網域、人工代營運、小遊戲／健康加購模組、未另約的客製功能。AI 不保證一次達成所有需求；預覽與健康展示不是醫療診斷或真實檢測。不能用未完成模組宣稱已可交付。

## 付款與開通

採 LINE Pay 一次性付款。付款成功需伺服器向 LINE Pay 核對訂單、交易編號、TWD 與金額後，才開通該會員專案；不以返回頁或截圖直接判定。交易待核對時不要重複付款，請提供訂單編號給客服。付款資料由 LINE Pay 處理，本網站不蒐集完整卡號或付款密碼。

平台資源不足或服務暫停時應先告知並協助處理，不以已扣款為由拒絕提供約定服務；正式收費前需完成實際建置驗收及足以交付已售額度的資源安排。

## 退款與申訴（待營運者確認）

請寄至客服 Email，提供訂單編號、問題描述及必要的去識別化畫面，勿附金鑰或完整付款卡號。

- 重複扣款：核對後處理重複部分退款。
- 已付款無法開通，或平台故障無法提供約定服務：聯絡客服排除；無法履行時受理退款。
- 其他退款申請：依適用法令、服務內容及實際履行情形處理，不以「一律不退款」排除法定權利。
- 本服務不預設所有數位服務均免除七日解除權，也不把一般購買勾選當作放棄權利。
- 退款目前由客服人工於商店後台處理；核准範圍、進度與付款機構作業時間另行通知。不宣稱已建置自動退款或發票系統。
- 退款涉及的未用權限／次數由客服核對後處理；不得先刪除交易紀錄。

## 隱私與資料使用告知（草稿）

蒐集目的：LINE 會員識別、保存專案設計、履行建置與付款服務、客服、交易核對、安全防護。資料類型包含 LINE 使用者識別碼與顯示名稱、專案需求／上傳的背景圖片、產生的程式與建置紀錄、訂單編號／金額／狀態／交易識別、必要服務紀錄及使用者主動提交的客服資料。不要上傳無權使用的圖片、他人個資、醫療資料或認證金鑰至需求文字。

必要服務供應者包括 LINE／LINE Pay（登入付款）、Supabase（資料庫與後端）、GitHub Pages（公開網站），及 OpenAI（AI 建置）。建置時會傳送需要的專案需求文字給 OpenAI；平台不應將伺服器金鑰混入建置需求。使用者授權部署時，程式可傳送至其指定 GitHub 與 Supabase；公開 Repository／Pages 的程式與內容會公開，請勿放私密資料。

資料可能隨必要的雲端服務跨境處理。專案按 LINE 身份隔離；伺服器服務金鑰不提供給一般客戶；沒有絕對零外洩風險承諾。使用者暫交的部署憑證僅供指定部署工作；實際保存與清除方式依部署程式紀錄及服務供應者機制，不能把需求交接連結到期說成所有副本會自動消失。
